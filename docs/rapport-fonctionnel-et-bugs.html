1. Résumé exécutif

L’application EGC est une application chrétienne multiplateforme permettant de consulter les contenus de l’église, s’inscrire, consulter les événements, regarder les directs et prédications, faire une demande de don, lire la Bible et administrer les inscriptions et annonces.

État global après validation : fonctionnel, avec réserves documentées ci-dessous.

  • Build frontend validé.
  • Lint frontend validé sans erreur.
  • Tests backend validés : 6 tests sur 6.
  • API de production Railway joignable sur HTTPS.
  • Correction publiée pour l’administration Android qui utilisait auparavant localhost:8080.

4. Formulaire d’inscription : données et réponses

  • Identité : nom, prénom et date de naissance.
  • Localisation : adresse, ville et arrondissement.
  • Contact : numéro principal obligatoire et second numéro facultatif.
  • Foi : réponse baptisé(e) ou non.
  • Statut dans l’église : Assistant(e), En service ou En formation.
  • Département : Accueil, Chantre, Sonorisation, Sécurité, Logistique, NTIC, Administration, Communication (Com) ou Traduction. Le département apparaît lorsque le statut « En service » est choisi.

Le backend empêche les doublons confirmés pour une même activité et un même numéro normalisé. Les nouvelles soumissions d’un dossier existant repassent en attente.

6. Rapport de bugs et anomalies

BUG-001 — Administration Android inaccessible avec l’ancienne APK

Gravité : élevée   État : corrigé dans le code source, nouvel APK requis.

Cause : l’application native utilisait http://localhost:8080. Sur un téléphone, localhost désigne le téléphone, pas l’API Railway.

Correction : ajout d’une configuration API qui utilise automatiquement l’URL Railway sur Capacitor et localhost uniquement en développement web.

Correction livrée : un nouvel APK Android version 1.1 a été généré avec le bundle local et l’URL API native corrigée.

BUG-002 — Demande de prière non encore implémentée

Gravité : moyenne   État : fonctionnalité en développement.

L’écran informe l’utilisateur que la fonctionnalité sera disponible dans une prochaine mise à jour. Aucun envoi de demande n’est actuellement décrit comme opérationnel.

BUG-003 — Réseaux sociaux du pied de page

Gravité : faible   État : à vérifier.

Les boutons Facebook, TikTok et YouTube sont présents mais certains liens sont encore des liens génériques #. Ils doivent être remplacés par les URL officielles de l’église.

BUG-004 — Fonctionnalités réseau dépendantes d’Internet

Gravité : informative   État : comportement attendu.

Les annonces non encore mises en cache, les inscriptions, les dons, l’administration, YouTube et la carte nécessitent une connexion. L’interface et les données locales déjà enregistrées restent disponibles hors connexion.

BUG-005 — APK à régénérer après les corrections

Gravité : élevée pour la distribution   État : corrigé pour la nouvelle APK.

Le code source est à jour sur GitHub et une nouvelle APK version 1.1 a été générée. Une application déjà installée doit être mise à jour ou réinstallée manuellement.

8. Recommandations de mise en production

  1. Installer l’APK version 1.1 sur un téléphone sans connexion puis avec connexion pour vérifier les deux modes.
  2. Tester une connexion admin, l’affichage des inscriptions, les filtres de départements et la modification d’une fiche.
  3. Remplacer les liens sociaux génériques par les liens officiels.
  4. Implémenter la soumission réelle des demandes de prière si cette fonctionnalité est prioritaire.
  5. Mettre en place une procédure de sauvegarde de la base SQLite et de vérification des variables secrètes Railway.
